# AI Applications

This directory is managed by the `apps-ai` Argo CD parent Application. Add AI
workloads in a child directory with an `app.yaml` manifest.

- `hermes/`: Hermes Agent.
- `openwebui/`: Open WebUI, with authenticated tailnet-only HTTPS access.
  See [deployment and setup](../../../docs/openwebui.md).
- `paperclip/`: Paperclip agent orchestration, with authenticated tailnet-only
  HTTPS access. See [deployment and setup](../../../docs/paperclip.md).
